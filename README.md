# Практична робота № 7–8

Тема: «Формула повної ймовірності та формула Байєса в ймовірнісній класифікації та діагностиці програмних систем».

**Студент:** Римаренко Євгеній Олександрович  
**Група:** ІВ-25-1  
**Варіант:** 1

## Залежності

Python 3.10 або новіший, matplotlib.

```powershell
python -m pip install matplotlib
```

## Блоки роботи

- `src/block1.py` — байєсівське оновлення для системи виявлення атак.
- `src/block2.py` — локалізація джерела збоїв серед трьох серверів.
- `src/block3.py` — класифікація Spam/Ham за двома словами та оцінка якості.
- `src/block4.py` — класифікація листів за трьома словами, варіант 1.
- `src/main.py` — послідовний запуск усіх чотирьох блоків.

## Запуск

Із головної папки проєкту:

```powershell
python src/main.py
```

Окремий блок запускається так:

```powershell
python src/block1.py
python src/block2.py
python src/block3.py
python src/block4.py
```

Усі блоки виводять результати в термінал. Графіки записуються у `graphics/`.
Готовий звіт із розрахунками та таблицями: [PDF](report/PR7_8_Report_Rymarenko.pdf).
Вікна графіків автоматично не відкриваються.

Для відтворення результатів у кожному блоці використано окреме фіксоване
зерно генератора випадкових чисел. Повторний запуск оновлює результати
та графіки відповідного блоку.

## Параметри блоку 4

У методичці для варіанта 1 задано частку спаму 0,20 та три бінарні ознаки,
але не наведено умовних ймовірностей слів. Для експерименту прийнято
умовну незалежність ознак і такі додаткові параметри моделі:

| Ознака | Слово | P(слово\|Spam) | P(слово\|Ham) |
|---|---|---:|---:|
| w1 | free | 0,80 | 0,05 |
| w2 | click | 0,60 | 0,10 |
| w3 | win | 0,70 | 0,05 |

Перші дві пари ймовірностей відповідають блоку 3; третя пара та слово `win`
обрані як параметри навчального експерименту. Вони не є заданими числами
варіанта. У коді ці значення можна змінити. Результати блоку 4 стосуються
саме цієї моделі, а не реального поштового набору даних.
